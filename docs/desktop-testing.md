# 桌面版测试指南

本仓库发布源码，不包含任何维护者的 Token、域名配置、签名证书、任务数据或预配置 App。首次运行请按 README 创建自己的 `.env` 和命名隧道配置；公开 MCP 的持有 Token 者可以调用本地文件及命令工具，默认目录不是沙箱。

## 自动回归

Python 3.11+，先激活虚拟环境，保证测试子命令也能找到 `python`：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
pytest -q
```

macOS 安装 Swift 命令行工具后：

```bash
bash tests/desktop/run.sh
```

Swift 自测在临时目录使用独立端口和假服务，不连接真实隧道，不运行收费 AI。覆盖环境解析、信号继承、端口占用保护、自有子进程收尾、网络地址变化、隧道失败后的本地任务保留、自动重试及协议解码。

本版发布前验证：Python 197 项通过（有一项上游 Starlette 弃用警告），Swift 生命周期和协议检查通过。真实 macOS App 已验证公网鉴权、文件读取、短命令执行及隧道退出后的自动恢复；不同网络环境须自行验证。

## 本机验收清单

1. 配置自己的凭据和 loopback 地址，执行 `bash scripts/install-desktop.sh`。仅使用 App 或 launchd 中的一种启动方式。
2. 打开 App，分别确认本地、公网和鉴权状态；工具清单应来自实际服务。
3. 使用自己的 MCP 客户端执行无副作用的只读调用和临时目录短命令，检查活动、任务状态与输出。
4. 最小化后检查公网调用；有运行中任务时关闭窗口，检查退出确认；取消退出后任务应继续。
5. 关闭或 Cmd-Q 后检查自有进程退出；不得终止占用端口的其他服务。重新打开后检查恢复。
6. 启用物理 IPv4 出口时，只调整隧道：网络切换或隧道失败不能取消本地任务。新网络仍须允许 Cloudflare 隧道连接。
7. Token 默认隐藏；日志应脱敏。截图、运行日志及本机验收记录留在本机，不提交。

更新安装时脚本会把旧 App 放入废纸篓供临时回滚；确认新版可用后，如仅需保留一个版本，请删除对应旧 App，桌面软链接不是第二份 App。
